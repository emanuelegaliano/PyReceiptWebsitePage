# PyReceipt Landing Page

Modern, clean, light-themed SaaS landing page for the **PyReceipt** ecosystem (OCR Engine & Conversational AI Chatbot).

> 📱 PyReceipt is now an Android app: **[Receipt](https://emanuelegaliano.github.io/Receipt/)** runs the OCR pipeline and the PyReceipt parser entirely on the phone, replacing the Telegram bot + separate OCR setup.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

The production output will be generated inside the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```

## 🎨 Features & Architecture
- **Vite 6** + **Tailwind CSS** + **Lucide Icons**
- **Light SaaS Theme**: Whites, soft grays, tech blue, mint green, and golden amber accents.
- **Hero Section**: Dynamic receipt scan simulation transforming into structured data and AI conversational dialogue.
- **Bento Grid**: Interactive cards for OCR Parsing, Conversational Chatbot, Smart Categorization, and Spending Analytics.
- **How It Works**: 3-step sequential visual breakdown (Capture, Process, Query).
- **Android App Section**: Before/after comparison and links to the [Receipt](https://github.com/emanuelegaliano/Receipt) app, website and APK.
- **Ecosystem Links**: Deep links to [PyReceipt](https://github.com/emanuelegaliano/PyReceipt) & [PyReceiptChatbot](https://github.com/emanuelegaliano/PyReceiptChatbot).
