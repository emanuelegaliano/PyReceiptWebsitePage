PyReceipt Is Now Receipt for Android

No more Telegram bot talking to an OCR model running somewhere else. The OCR pipeline and the PyReceipt parser have been ported to Dart and now run inside one app, on your phone, without an internet connection.

Before: PyReceipt

Python OCR engine + Telegram bot

Original
  • OCR model running separately on a server or Raspberry Pi.
  • Receipts sent through a Telegram chatbot to be read.
  • Commands like /add and /stats to manage expenses.

Now: Receipt

One Android app, all on-device

v0.1.0
  • RapidOCR (PP-OCRv4) with ONNX Runtime directly on the phone, about 3 seconds per scan.
  • No account, no cloud, no internet permission: data never leaves the device.
  • Categories that learn, monthly limits, card vs cash summaries and .zip backups.

How the Original PyReceipt Bot Works

Explore the real Telegram interface, OCR pipeline, manual entry wizards, and statistical breakdown features. Looking for the app? See Receipt in action.

1 Command Center & Onboarding

Instant Telegram Bot Onboarding

Launch the assistant with /start to access immediate interactive shortcuts. Everything is operated through clean Telegram commands and inline reply keyboards.

  • Instant command shortcuts for Manual Entry, Monthly Stats, and OCR Language.
  • Toggle QIF file format export on/off anytime with /qifon and /qifoff.
  • Quick cancellation of pending actions with /cancel.
Telegram // /start
ExpressExpense // Receipt OCR
2 Automatic OCR Ingestion

Snap a Photo & Extract Merchant, Amount and Date

Simply send any receipt image directly to the Telegram bot. PyReceipt utilizes Tesseract and RapidOCR to parse the receipt, classify the merchant, extract totals, and format the record.

Sample receipt illustrated above is sourced from the ExpressExpense dataset.
  • Automatic identification of Merchant (e.g. MOD Pizza), Amount (€29.98), Category (RESTAURANT), and Date.
  • Automatic generation of QIF text blocks ready for financial software imports (GnuCash, HomeBank).
  • Low-resource execution: runs effortlessly on lightweight local hardware and Raspberry Pi.
3 Guided Manual Entry

Fast Manual Commands & Confirmation Wizard

When you have a cash transaction or quick receipt without a picture, log it in one line with /add 28 Fresh Pizza NYC RESTAURANT or step-by-step with /manual.

  • Fast one-line input syntax: /add <amount> <merchant> <category>
  • Interactive confirmation buttons to edit Amount, Category, or Merchant before saving.
  • Instant SQLite storage with atomic transaction safety.
Telegram // /add wizard
Telegram // /stats
4 Expense Summaries & Statistics

Real-Time Monthly & All-Time Summaries

Stay in control of your financial spending with simple statistical commands. View monthly totals and category breakdowns anytime.

  • Run /stats or /month to view current month expense metrics.
  • Query historical periods using /stats YYYY-MM (e.g. /stats 2019-06) or /stats all.
  • Clear category-level totals (GROCERIES, RESTAURANT, TRANSPORT).
5 Multi-Language Configuration

Dynamic OCR Language Switching (IT / EN)

Switch the active OCR parser language on the fly using the /lang command to maximize optical accuracy across Italian and English receipts.

  • Support for 🇮🇹 Italiano and 🇬🇧 English receipt structures.
  • Interactive inline buttons to toggle language immediately without restarting the bot.
  • Adapts date formats and keyword parsing to the chosen locale.
Telegram // /lang switcher
